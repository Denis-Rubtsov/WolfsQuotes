# Волчьи цитаты

Telegram-бот на .NET 8, который хранит и раздаёт цитаты «от Волка»: пользователи могут листать их в личке и inline-режиме, предлагать свои, а админы — модерировать базу и генерировать новые цитаты через ChatGPT.

## Возможности

**Для всех пользователей**
- `/start`, `/help` — приветствие и список команд.
- `/guide` — подробный гайд по всем возможностям бота (админы видят расширенную версию с админскими командами).
- `/quote` — случайная цитата с кнопками 👍/👎 (один голос на пользователя, повторное нажатие снимает голос).
- `/list` — вся база цитат пронумерованным списком.
- `/suggest` — предложить свою цитату; после подтверждения она уходит на модерацию всем админам.
- `/generate` — если админы открыли публичную генерацию (`/publicgen`), доступна генерация цитаты через ChatGPT; результат уходит в очередь предложений на модерацию. Действует лимит 5 генераций в час на пользователя; сверх лимита бот выставляет счёт в звёздах Telegram (цена — из `/setprice`, изначально берётся из ключа `StarsPrice`), оплаченные генерации хранятся в базе и не сгорают при ошибке генерации или перезапуске.
- `/paysupport` — поддержка по вопросам оплаты звёздами.
- Inline-режим: `@botname` (случайная цитата), `@botname 5` (цитата №5 из `/list`).

**Для админов** (см. [ADMIN_IDS](#конфигурация))
- `/addquote` — добавить цитату напрямую, минуя модерацию.
- `/editquote <номер>` — заменить текст существующей цитаты.
- `/deletequote <номер>` — удалить цитату (с подтверждением).
- `/generate` — сгенерировать цитату через ChatGPT (стиль подбирается по случайным существующим цитатам), с кнопкой перегенерации перед добавлением.
- Inline `@botname ai` — то же самое прямо в любом чате.
- `/publicgen` — открыть/закрыть генерацию через ИИ для обычных пользователей (флаг сохраняется в базе и переживает перезапуск).
- `/setprice <число>` — изменить цену генерации сверх лимита в звёздах Telegram (сохраняется в базе и переживает перезапуск; `0` отключает продажу).
- `/listsuggest`, `/approve <номер>`, `/reject <номер>` — очередь предложений от пользователей.
- `/stats` — статистика: размер базы, очередь предложений, голоса, топ цитат по лайкам.
- `/export` — бот присылает JSON-файл базы (бэкап в один клик).
- При добавлении любой цитаты (вручную, через ИИ или одобрением предложения) уведомляются все остальные админы.
- Меню команд Telegram (кнопка `/`) для админов автоматически расширено этими командами; обычные пользователи видят `quote`/`suggest`/`list`/`guide`/`help`, а пока открыта публичная генерация (`/publicgen`) — ещё и `generate`.

## Структура проекта

```
Vlk/
├── Program.cs          — точка входа, чтение конфига, сборка зависимостей
├── BotService.cs        — обработка команд и callback-кнопок
├── InlineHandler.cs      — обработка inline-режима
├── AiQuoteService.cs     — генерация цитат через OpenAI Chat API
├── QuoteService.cs       — вспомогательная логика над базой цитат
├── DataService.cs        — чтение/запись JSON-файла с данными
├── BotData.cs / Suggestion.cs — модели данных
└── appsettings.json      — конфигурация (токен, админы, ключ API и т.д.)
```

Данные (цитаты и предложения) хранятся в JSON-файле, путь к которому задаётся в `QuotesFile`.

## Конфигурация

Настройки задаются в `Vlk/appsettings.json` или переменными окружения (переменные окружения имеют приоритет).

| Ключ | Описание |
|---|---|
| `TelegramBot:Token` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | ID админов через запятую/точку с запятой/пробел, например `123456789,987654321`. Узнать свой ID можно у `@userinfobot` |
| `AiApikey` | API-ключ OpenAI для генерации цитат |
| `SystemPromptFile` | Путь к текстовому файлу с системным промптом для генерации (перечитывается на каждый запрос, менять можно без перезапуска; если файла нет — используется встроенный промпт) |
| `QuotesFile` | Путь к JSON-файлу с базой цитат и предложений |
| `BASIC_URL` | Базовый URL для голосовых версий цитат (используется в inline-режиме) |
| `StarsPrice` | Начальная цена одной генерации сверх бесплатного лимита в звёздах Telegram (по умолчанию `10`; `0` отключает продажу). Используется, пока админ не изменит цену командой `/setprice` — после этого приоритет у значения из базы |

Пример:

```json
{
  "TelegramBot": { "Token": "123456:ABC-DEF..." },
  "ADMIN_IDS": "123456789,987654321",
  "AiApikey": "sk-...",
  "QuotesFile": "quotes.json",
  "BASIC_URL": "https://example.com/voices/"
}
```

## Запуск

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
cd Vlk
dotnet restore
dotnet run
```
